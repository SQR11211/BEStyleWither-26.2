# BE Style Wither — Minecraft 26.2 NeoForge port

An **unofficial** community port of [BEStyleWither](https://github.com/MORIMORI0317/BEStyleWither)
by **MORIMORI0317** to **Minecraft 26.2 / NeoForge**, maintained by **SQR11211**.

The mod brings the Wither's behavior closer to Bedrock Edition. This port adds an
independent BE-style Wither entity that is summoned using 3 Skeleton Skulls on top of
Soul Sand / Soul Soil.

> This project is not affiliated with or endorsed by the original author.

## Requirements

| | |
|---|---|
| Minecraft | 26.2 |
| NeoForge | 26.2.0.95 or newer |
| Java | 25 |

## Building

```bash
./gradlew build
```

The mod jar is written to `build/libs/bestylewither-26.2-1.8.0.jar`.
